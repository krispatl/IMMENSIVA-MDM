VENUE OPERATIONS / QUICK START

Quick start

Use IMMENSIVA MDM to group headsets, install apps, transfer files and check device status.

Daily operation

1 / Open

Double-click Start IMMENSIVA MDM.cmd. Keep the PC awake.

2 / Connect

Wake each headset. Open STYLY-MDM Client and use Auto-Discovery. Wait for Online.

3 / Select

Choose a room or tick headsets. Check the selected names and battery levels.

4 / Open the app

Choose Open app, pick Lord Lyrical, then Open on selected headsets. Review the list and confirm.

For JERU: participants align in their headsets, then start the performance from Show launcher.

First-time setup / Connect the venue

  1. Keep the venue PC and PICO headsets on the same trusted local network. Open IMMENSIVA MDM on the PC.
  2. Install the official STYLY-MDM Client APK on each PICO Business headset. The Client APK link in the console downloads the matching version.
  3. Open STYLY-MDM Client in the headset and choose Use Auto-Discovery. If broadcast discovery is unavailable, enter the PC’s LAN address with port 7070, then Save & Connect.
  4. For remote APK installs, allow the MDM client’s All files access during provisioning. An organisation/device-management approval may also need to be accepted in the headset.

02 / Make a room

  1. Choose Rooms & groups. Create a name such as Gallery, Studio or Lord Lyrical.
  2. Select the intended headsets as members and save. Give devices clear labels so operators can identify the physical headset.
  3. Back in the console, choose a room or individual headsets. Check online status and battery before acting.

03 / Install an experience

Expand Install an experience, choose its .apk and click Install to Selected. The console shows dispatch and installation results. Offline devices are skipped. A command being sent is not the same as a successful install; check each result in the activity log.

04 / Open the app

Click Lord Lyrical to fill its app package, or enter another Android package under Open app. Select the intended online headsets, then click Open on selected headsets. This opens the app; Lord Lyrical’s separate show launcher starts the synchronised performance after alignment.

05 / Files, integrity and maintenance

Use Push Files for assets in shared storage, Verify for APK/folder checks and Update MDM Client for compatible client updates. Folder Sync can delete extra files; Uninstall, Retire, Reboot and Power Off affect devices immediately. Keep their existing confirmations and review the selected targets before proceeding.

LBE maps are a separate layer.

PICO Business Device Manager creates/distributes/applies the shared LBE room map. IMMENSIVA MDM manages apps and files. It does not establish physical alignment. Check real room markers across headsets and retain Lord Lyrical’s shared floor-mark/stage alignment.

When something does not connect

  • Check the PC and headset network addresses. Different isolated subnets can block discovery.
  • Allow venue TCP 7070 and discovery UDP 7071 only on the trusted venue network.
  • If a client entered standby before the server started, reopen its app, toggle Wi-Fi or reboot the headset to start a new discovery window.
  • If no devices appear, check the headset client and network connection.
  • Do not run two discovery servers on the same venue network/port.
